# Napp open data

- `coastal-osm.json`: the parts of the Napp app's coastal data derived from OpenStreetMap (sea bay names and points, and the Åland and Finland boundary lines, simplified). © OpenStreetMap contributors, available under the Open Database License (ODbL) 1.0: https://opendatacommons.org/licenses/odbl/1-0/. Built by the app's coastal builder from Overpass API data; the OSM date is in the file.
